# Sprint 2 Arcade Screen Saver for macOS

An independent fan-made screen saver inspired by Atari/Kee Games Sprint 2
(1976). This public package contains the finished macOS screen saver only;
the Python source code is not included.

## Install

1. Download the latest ZIP from the GitHub Releases page.
2. Unzip it.
3. Double-click `Sprint 2 Arcade.saver`.
4. Open **System Settings → Wallpaper → Screen Saver**.
5. Select **Sprint 2 Arcade** and choose **Options**.
6. Select a preset or scroll through the 40 individual effects, then press
   **Save**.

The package includes both Intel and Apple Silicon builds. It requires macOS
13 or later and does not require Python, Pygame, or an internet connection.

## macOS Tahoe Options workaround

Some Tahoe installations do not open third-party screen saver options the
first time. Quit System Settings completely with **Command-Q**, reopen it,
and try again. If it still does not work, double-click `Sprint 2 Settings.app`
in this package. It opens the same settings panel directly.

## Presets

- **Original** — sharp monochrome arcade presentation;
- **CRT** — restrained curved tube, scanlines, glow, and flicker;
- **LCD** — slow color cycling;
- **Arcade FX** — the complete 40-effect set;
- **Custom** — individually selected effects.


## Security note

This release is locally signed but not notarized by Apple. macOS may require
an approval under **System Settings → Privacy & Security** after installation.
